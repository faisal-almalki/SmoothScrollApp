# حراج فيديو — تطبيق Expo (آيفون + أندرويد)

تطبيق تجريبي كامل بنظام React Native / Expo: خلاصة فيديو عمودية بأسلوب تيك توك،
كل مقطع يحمل إعلاناً، ويقدر أي شخص يصوّر مقطعه وينشره — تطبيق واحد يشتغل على
الآيفون والأندرويد.

نشأ من تجربة صغيرة (feed only) بعد ما أثبتت إن أداء الفيديو سلس على الجهاز.

## تشغيله على جوالك

```bash
cd spike-expo-feed
npm install
npx expo start
```

يطلع رمز QR. حمّل **Expo Go** من المتجر، افتح الكاميرا ووجّهها على الرمز.
(خلّ الجوال والكمبيوتر على نفس شبكة الواي فاي.)

## وش يشتغل

- **الرئيسية** — خلاصة فيديو عمودية، ثلاثة مشغّلات معاد استخدامها للسلاسة، مع
  بطاقة الإعلان فوق كل مقطع، إعجاب، وكتم/تشغيل الصوت.
- **تصفّح** — بحث + فلاتر تصنيف ومدينة + شبكة إعلانات.
- **تصوير** (زر النجمة) — كاميرا حقيقية، تسجيل حتى ٦٠ ثانية، قلب الكاميرا،
  معاينة، وصف، ربط إعلان، ثم نشر المقطع للخلاصة.
- **الرسائل** — صندوق الوارد ومحادثة لكل إعلان (مع رد تلقائي تجريبي).
- **حسابي** — تسجيل دخول برقم الجوال، إعلاناتي، نشر إعلان جديد.
- **تفاصيل الإعلان** — راسل البائع أو اتصل (لما ينشر رقمه)، متابعة البائع.

## الحالة

بيانات محلية (بدون خادم) — كل شي يشتغل ويُحفظ على الجهاز عشان تجربه فوراً.
التصميم مطابق لاستجابات الخادم (server/) حرفاً بحرف، فربطه بالـ API لاحقاً هو
تبديل طبقة `src/data/store.ts` بنداءات fetch، بدون تغيير أي شاشة.

الخادم الكامل (تسجيل دخول، إعلانات، رسائل فورية، إشعارات، تخزين فيديو) جاهز في
مجلد `server/` — ١٣١ فحص ناجح.

## البنية

```
app/                 شاشات expo-router
  (tabs)/            الخمس تبويبات
  listing/[id]       تفاصيل الإعلان
  chat/[id]          محادثة
  seller/[id]        صفحة البائع
  preview, post, login
src/
  components/Feed    الخلاصة (مشغّل الفيديو المجمّع)
  data/              الأنواع، البيانات المزروعة، المخزن
  lib/               الثيم، العملة، خطاف التركيز
```

## التحقق

`npm run typecheck` (بدون أخطاء) و `npm run bundle` (يجمّع التطبيق كاملاً).
